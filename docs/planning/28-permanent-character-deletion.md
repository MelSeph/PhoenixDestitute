# Permanent character deletion — 2026-11-15

The user explicitly changed the deletion requirement: **“if a player deletes their character, it is completely destroyed from the ether.”** This supersedes Phase 2Q's logical deletion/history retention. Typed-name confirmation and session ownership checks remain.

The delete service now permanently removes only the selected Player/Legacy story: death entries/snapshots, equipment reservations, owned enchantments/items, per-life saves, births, internal predecessor links/lives, roster entry, Player (cascading its compatibility save/settings), playable Characters, and Legacy. Temporary confirmed drafts and active selection are cleared as appropriate; unrelated unfinished drafts and other saved stories remain. Shared definitions and accounts are untouched. All steps run in the existing transaction; any protected reference from another story rejects the operation and rolls everything back instead of broadening its scope. Protected model relationships are not weakened globally.

There is no tombstone or recovery copy created by in-game deletion. Previously existing external backups are outside this operation and are not modified. The old nullable `deleted_at` column remains for compatibility with migration 0018, but the new Delete action does not use it. A repeated request returns the same privacy-preserving 404 as a missing/foreign target; Reload characters recovers a lost response without replaying deletion.

The dialog explicitly warns that the entire saved story and history will be destroyed and cannot be undone. Tests verify true absence of records, multi-life/item/death-history deletion, preservation of another story/shared definitions, and rollback on cross-story references. **All 298 Django tests pass, none skipped; all 8 character-management browser tests pass; production build succeeds.** Existing appearance/birth behavior was not otherwise changed. No schema migration or live user-data purge is required for this behavior change. Preview servers restored. No commit/push.
